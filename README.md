# Garuda

Bahasa pemrograman baru yang sederhana, cepat, dan konkuren.

## Tujuan awal

- Sintaks minimalis seperti Go
- Compile ke native machine code
- Konkurensi bawa-bawa (goroutine & channel)
- Kompilasi cepat
- Bootstrappable (bisa compile dirinya sendiri)
